# Operator documentation

Choose the guide for the work you are doing:

- [Deploy and operate W&B](user/README.md): install published Operator releases,
  configure W&B and its infrastructure, and manage a running deployment.
- [Develop Operator](developer/README.md): run a local environment, change the
  controller and APIs, test changes, and publish releases.
- [Design records](design/README.md): implementation rationale, proposals, and
  historical architecture notes.

These guides describe the v2 code in this checkout. Use documentation from the
tag matching your installed release when fields differ. Operator v1 maintenance
lives on the [v1 branch](https://github.com/wandb/operator/tree/v1).
