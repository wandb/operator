# SeaweedFS Operator API Vendored Code

This directory contains vendored API types from the [SeaweedFS Operator](https://github.com/seaweedfs/seaweedfs-operator) project.

## Source

- **Repository**: https://github.com/seaweedfs/seaweedfs-operator
- **Operator Version**: 1.0.32
- **Helm Chart Version**: 0.1.35
- **Date Vendored**: 2026-07-17

## Reason for Vendoring

To have full control over the CRD API types and avoid unexpected breaking changes when the upstream operator updates. This allows the W&B operator to manage SeaweedFS clusters while controlling when and how we adopt upstream changes. Vendoring also avoids pulling in the full SeaweedFS server dependency tree via go.mod.

## Changes Made

### API imports and local DeepCopy generation

The Go declarations in `seaweed.seaweedfs.com/v1/types.go` are a curated snapshot
of upstream API definitions, not a locally generated CRD schema. Import API
changes from their upstream source; do not invent fields or hand-edit generated
DeepCopy methods or CRDs. The `ComponentSpec` security-context fields come from
[upstream commit 9d384588856b8a154af6fbb87100eb6d639fa608](https://github.com/seaweedfs/seaweedfs-operator/blob/9d384588856b8a154af6fbb87100eb6d639fa608/api/v1/seaweed_types.go),
already supported by the pinned controller 1.0.32 / chart 0.1.35 and its CRD.
This is a selected API import, not an operator or schema upgrade.

CRD validation/webhook annotations remain stripped. Object-generation markers
are intentionally retained: the package's `+kubebuilder:object:generate=true`
and the `Seaweed`/`SeaweedList` `+kubebuilder:object:root=true` markers allow the
repository-pinned `controller-gen` to regenerate deep copies, including the
imported security-context pointers. After importing API definitions, run:

```sh
make generate-seaweedfs
```

The generator reads the Go types in this package and writes only
`zz_generated.deepcopy.go`; do not edit that output. `make generate` also runs
this target. Repeating it must leave the generated file unchanged. SeaweedFS's
CRD remains the chart/upstream artifact and is not generated by this target.

### Removed Files

- `component_accessor.go` - Runtime helpers not needed for CR creation/status reading
- `seaweed_webhook.go` - Webhook logic not needed
- `seaweed_webhook_test.go` - Tests

### Added Files

- `vendored_helpers.go` - GroupName constant
